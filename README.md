## Escopo

Reunir projetos de estudo e experiências de desenvolvimento em backend, web e mobile, com links para os repositórios e uma descrição do trabalho em cada projeto.

## Identidade visual

O design é o da versão criada no ChatGPT Sites, mantido como estava. Por cima dele entram a marca "ad." e o modo noturno:

- Logo `>ad.` em Space Mono, peso 700. O `>` é a nave, o ponto dourado é a estrela.
- Lema: *per aspera ad astra*.
- Modo noturno com a paleta Tokyo Night, alternado pelo botão no cabeçalho. A escolha fica salva no navegador; na primeira visita vale a preferência do sistema.

## Estrutura

```
index.html    marcação e conteúdo
styles.css    design original (modo claro)
theme.css     logo >ad., botão de tema e modo noturno
script.js     filtros, modal de projeto, copiar e-mail e troca de tema
assets/       favicon
```

HTML, CSS e JavaScript puros, sem etapa de build.

## Como rodar

Abra `index.html` no navegador, ou sirva a pasta:

```bash
npx serve .
```
