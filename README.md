## Escopo

Reunir projetos de estudo e experiências de desenvolvimento em backend, web e mobile, com links para os repositórios e uma descrição do trabalho em cada projeto.

## Identidade visual

O site segue a identidade "ad.":

- Logo `>ad.` em Space Mono, peso 700. O `>` é a nave, o ponto dourado é a estrela.
- Lema: *per aspera ad astra*.
- Paleta Tokyo Night. Os tokens ficam no topo de `css/styles.css`.

| Papel | Cor |
| --- | --- |
| Fundo | `#1a1b26` |
| Fundo profundo | `#16161e` |
| Superfície | `#24283b` |
| Borda | `#414868` |
| Texto | `#c0caf5` |
| Comentário | `#8089b3` |
| Nave `>` e links | `#7aa2f7` |
| Estrela `.` | `#e0af68` |

## Estrutura

```
index.html        marcação e conteúdo das seções
css/styles.css    tokens da identidade e estilos
js/projects.js    dados dos projetos (edite aqui para adicionar um)
js/main.js        cards, filtros e modal de detalhes
assets/           favicon
```

HTML, CSS e JavaScript puros, sem etapa de build.

## Como rodar

Abra `index.html` no navegador, ou sirva a pasta:

```bash
npx serve .
```
